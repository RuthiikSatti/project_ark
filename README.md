# Project ARK

Personal-server configuration and automation for Nextcloud on Windows/Docker.

## Included

- Docker Compose configuration for Nextcloud and MariaDB
- Backup, health-check, recovery, notification, and Nextcloud cron scripts
- Smart Organizer source code

## Safety

Secrets, WireGuard private keys, backups, storage data, reports, virtual environments, and personal files are intentionally excluded from version control.
